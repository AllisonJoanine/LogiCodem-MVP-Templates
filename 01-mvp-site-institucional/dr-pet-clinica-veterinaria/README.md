# Dr Pet Clínica Veterinária

Código completo do site demonstrativo criado para a Dr Pet Clínica Veterinária,
em Sorocaba.

## Tecnologias

- Next.js 16
- React 19
- TypeScript
- Lucide React
- CSS responsivo sem framework visual obrigatório

## Executar localmente

Requisito: Node.js 22 ou superior.

```bash
npm install
npm run dev
```

Depois, abra `http://localhost:3000`.

## Gerar versão estática

```bash
npm run build
```

O site exportado será criado na pasta `out/`. Essa pasta pode ser enviada para
uma hospedagem estática, como GitHub Pages, Cloudflare Pages ou Netlify.

## Arquivos principais

- `app/page.tsx`: conteúdo e estrutura da página
- `app/globals.css`: identidade visual, animações e responsividade
- `app/layout.tsx`: título, descrição e SEO
- `public/images/`: imagens conceituais utilizadas no site
- `public/favicon.svg`: ícone do projeto

## Observação

Este é um conceito demonstrativo não oficial. As imagens são ilustrativas e as
informações públicas da empresa devem ser reconfirmadas antes de uma publicação
oficial.
