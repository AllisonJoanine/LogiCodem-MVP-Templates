# Alex • Boston Terriers

Site institucional estático e responsivo para apresentação de um canil de Boston Terriers, com perfis demonstrativos, ninhadas, galeria, FAQ e chamadas para conversa pelo WhatsApp.

Esta edição foi preparada para funcionar diretamente no GitHub Pages, sem servidor ou etapa de compilação. Abra `index.html` com um servidor local ou acesse a demonstração publicada:

https://allisonjoanine.github.io/LogiCodem-MVP-Templates/21-mvp-site-canil/opcao-01-alex-boston-terriers/

Antes de uso comercial, substitua os campos entre colchetes pelos dados reais fornecidos pelo responsável pelo canil.
